### B2. 2026 AI 서버 설계 메가트렌드

**트렌드 1: 액냉(Liquid Cooling) 표준화**
- B200 (1,000W), MI355X (1,400W) → 공랭 불가
- 전통 IDC의 최대 도전: 냉각 인프라 전면 교체 필요
- **NPU 기회:** 35-70% 전력 절감 → 기존 공랭 IDC에서 운영 가능

**트렌드 2: 추론 >> 학습 (워크로드 시프트)**
- 2026년 추론이 전체 컴퓨팅의 약 2/3 차지 (Deloitte)
- 추론 최적화 칩 시장 $50B+ (2026)
- GPU는 학습에 최적, 추론에는 과잉 스펙 → NPU의 존재 이유

**트렌드 3: 랙 스케일 아키텍처**
- NVIDIA: GB200 NVL72 (72 GPU = 1 랙 = 1 도메인)
- AMD: Helios (MI400 + EPYC Venice + Pensando, 풀 랙)
- SambaNova: SN50 DataScale (랙 단위)
- 개별 서버 → 랙 단위 시스템으로 전환

**트렌드 4: 하이퍼스케일러 자체 실리콘 확대**
- Google TPU, AWS Trainium/Inferentia, MS Maia, OpenAI Titan
- NVIDIA/AMD 의존도 감소 의지
- 2026 커스텀 ASIC 성장률(44.6%) > GPU 성장률(16.1%)

**트렌드 5: 에이전틱 AI와 Long-Context**
- 에이전트가 수분~수시간 연속 추론 → 전력 효율 중요
- 10M+ 토큰 컨텍스트 → 메모리 요구량 폭증
- SambaNova SN50: 10T 파라미터, 10M 토큰 컨텍스트 주장

**트렌드 6: 공급망 다변화**
- 미-중 수출 통제 → 비-NVIDIA 대안 수요 급증
- 사우디: Groq 7,500억원, UAE: Cerebras 1.5조원 구매
- 한국: Rebellions 정부 매출 70억원 (규모 대비 미미)

## Part C — 경쟁 차별화 및 기술 영업 전략

### C1. NPU vs GPU — 핵심 차별화 포인트 (영업용)

**고객에게 전달할 5대 메시지:**

#### 메시지 1: "추론에서 GPU는 과잉 설계다"
```
배경: GPU는 학습(Training)을 위해 설계되었다.
- 학습: 높은 FP16/FP32 정밀도, 역전파, 대규모 배치
- 추론: INT8/INT4 정밀도, 순방향만, 낮은 레이턴시

차별화 논거:
- GPU의 Tensor Core는 추론 시 30-50%만 활용됨
- NPU는 추론 연산만 탑재 → 같은 전력에서 더 높은 처리량
- MDPI 연구: NPU가 GPU 대비 35-70% 전력 절감하면서 동등 이상 처리량

고객 반론 대응:
"하지만 GPU면 학습도 추론도 다 되잖아요?"
→ "맞습니다. 하지만 추론이 전체 워크로드의 2/3이고, 
   24/7 운영되므로 TCO에서 전력비가 지배적입니다.
   학습은 GPU 클라우드, 추론은 NPU 온프레미스 — 이 하이브리드가 최적입니다."
```

#### 메시지 2: "전력 = 돈이다. NPU는 전기세를 절반으로 줄인다"
```
TCO 비교 (3년, LLaMA 70B 서빙, 500 req/s):

항목               | 8×H100 서버 4대 | NPU 서버 (동등 성능)
하드웨어           | ₩5.2억         | ₩3-4억
전력(3년)          | ₩2.1억         | ₩0.9억 (57% 절감)
냉각(3년)          | ₩0.6억         | ₩0.3억
IDC 상면(3년)      | ₩1.1억         | ₩0.7억 (랙 수 감소)
총 TCO             | ₩9.0억         | ₩5-6억

*NPU 벤더/모델에 따라 변동, 핵심은 전력 + 냉각 절감*

킬러 팩트:
- 한국 산업용 전기요금 ~120원/kWh
- H100 서버(10kW) × 24h × 365일 = ₩1,051만원/년/대
- NPU 서버(4kW, 동등 성능) = ₩420만원/년/대
- 4대 기준 차이: ₩2,524만원/년 절감
```

#### 메시지 3: "기존 IDC를 버리지 않아도 된다"
```
문제: B200은 1,000W TDP → 액냉 필수 → 기존 IDC 사용 불가
기회: NPU는 같은 성능을 300-500W에서 달성 → 기존 공랭 IDC 활용

고객 시나리오:
"우리 IDC는 랙당 20kW 한계입니다. B200은 넣을 수 없습니다."
→ "NPU 서버라면 랙당 20kW 안에서 더 많은 추론 성능을 배치할 수 있습니다.
   액냉 전환 없이 즉시 배포 가능합니다."

차별화: 인프라 전환 비용 제로 또는 최소화
```

#### 메시지 4: "레이턴시가 사용자 경험을 결정한다"
```
Groq LPU 벤치마크:
- TTFB: 0.22초 (GPU 평균 1-3초 대비)
- 처리량: 241 tok/s (독립 벤치마크)
- 100 토큰 출력: 0.8초 (GPU: ~10초)

비즈니스 임팩트:
- 챗봇 응답 속도 10배 → 사용자 만족도 직결
- 실시간 코드 생성: IDE 내 0.5초 응답 = 개발 생산성 혁신
- 음성 AI: 200ms 이내 응답 = 자연스러운 대화 경험

모든 NPU가 Groq 수준은 아니지만,
아키텍처 특성상 GPU 대비 낮은 레이턴시가 구조적 강점
```

#### 메시지 5: "공급망 리스크 분산"
```
현실:
- NVIDIA B200/GB200: 2026년 중반까지 품절 (백로그 360만 대)
- NVIDIA 의존 = 단일 공급처 리스크
- 미-중 수출 통제: 언제든 상황 변동 가능

NPU 대안:
- Groq: 미국 + 유럽 + 중동 데이터센터 12+ 곳 운영
- Cerebras: OpenAI 750MW 계약, 6개 추론 데이터센터 신규
- Rebellions: 삼성 4nm 파운드리, 한국 국산 → 수출 통제 리스크 낮음
- AWS Inferentia2: 클라우드 즉시 가용

영업 포인트:
"NVIDIA 납기 6-12개월 대기 vs NPU 솔루션 즉시 또는 3개월 내 배포"
```

#### vs NVIDIA (80-90% 시장 점유)
```

NVIDIA 약점: 가격, 전력 소비, 공급 부족, 벤더 락인

- "NVIDIA보다 빠르다" 단정 (벤치마크 없이)

- 학습 워크로드에서 NPU 우위 주장

```

2. 전력 비교: MI355X 1,400W vs NPU 300-500W (동등 추론 성능)
3. 메모리 우위 인정하되 → "추론에서는 메모리 크기보다 대역폭과 활용률"
4. 소프트웨어 비교: ROCm < CUDA < NPU 전용 SDK (추론 최적화 깊이)

프롬프트:
"고객이 AMD MI355X와 NPU 솔루션을 비교하고 있다.

클라우드 약점: 장기 비용, 데이터 주권, 벤더 락인, 커스터마이징 한계

3. 데이터 주권: "한국 금융/의료 규정 → 온프레미스 필수"
4. 하이브리드: 피크는 클라우드, 베이스라인은 온프레미스

프롬프트:
"AWS inf2 vs 온프레미스 NPU 서버의 3년 TCO 비교 스프레드시트를 만들어 달라.
트래픽 패턴(평균 500 req/s, 피크 2000 req/s),
